# Applications

## What it is
Applications are the real problems you solve with NLP and machine learning.

## The key intuition
The same core techniques appear again and again. The difference is the task and the evaluation.

## Common NLP applications in this repo
- Keyword extraction: `Identifying Keywords and Keyphrases From Text.ipynb`
- Topic modeling: `Identifying Topics From Documents.ipynb`
- Text summarization: `Extracting Summary Sentences From Documents.ipynb`
- Similarity search and clustering: `Practice_Embedding.ipynb`, `class_5/Hierarchical_Clustering.ipynb`
- Sentiment and named entity recognition: `class_6/NER.ipynb`, `class_6/Conduct_Sentiment.ipynb`

## Remember this
Use application pages when you want to recall which technique fits a problem, not just how the code works.
