# Glossary

This is your quick reference for the most important terms.

- **Tokenization**: splitting text into words, subwords, or characters.
- **Embedding**: a numeric vector that represents text meaning.
- **Feature representation**: the form text takes before modeling.
- **Classification**: predicting a label for text.
- **Clustering**: grouping similar texts without labels.
- **Evaluation**: measuring model quality with metrics.
- **NER**: named entity recognition, finding people/places/things in text.
- **Summarization**: extracting the main ideas from text.
- **Similarity metric**: a function that scores how alike two texts are.
