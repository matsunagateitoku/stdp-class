# NLP Notes

This is a memory-first companion for the NLP and machine learning notebooks in this repo.

The goal is to keep two separate layers:

- **Concept pages** for the main ideas and intuitions
- **Notebooks** for the code examples and experiments

Use this site when you want to remember what a technique is and why it matters. Follow the notebook links when you want to see the exact Python implementation.

## How to use this site

1. Read the concept page for the topic you need.
2. Review the key intuition and one short example.
3. Open the linked notebook when you need the code or a deeper worked example.
