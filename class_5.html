Class 5 — Clustering Documents With Unsupervised Machine Learning

This class covers document clustering techniques, including similarity metrics, hierarchical clustering, and K-Means on sentence embeddings.

Use these practical notebooks to explore cluster analysis and evaluate grouping quality.

Course Description

Class 5 explores similarity measures for text and unsupervised clustering approaches to group documents by similarity. It covers lexical similarity (Jaccard), edit distances (Hamming, Levenshtein), semantic embeddings (SBERT), hierarchical clustering and dendrograms, k‑means clustering on sentence embeddings, and evaluation metrics like silhouette score and adjusted Rand index (ARI). The class includes practical code labs on medoids, centroids, and choosing linkage methods.

Modules & Key Concepts

  • Use metrics to determine similarity — Jaccard similarity, Hamming distance, and edit-distance measures for string and document comparison.
  • Sentence embeddings & SBERT — encode sentences into dense vectors for semantic similarity, retrieval, and clustering.
  • Hierarchical clustering — agglomerative clustering, dendrograms, and linkage methods for grouping similar texts.
  • K‑means clustering — cluster sentence or document vectors, compare centroids and medoids, and evaluate cluster quality with silhouette score.
  • Project preview — encode movie descriptions and speeches into vectors, cluster them, and choose the best parameter sets using silhouette score and adjusted Rand index.
