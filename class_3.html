Class 3 — Classifying Documents With Supervised Machine Learning

This class covers labeled document classification, model training, evaluation, and improvement using supervised learning.

Key notebooks include logistic regression, confusion matrices, validation, and hyperparameter tuning for text classification.

Course Description

This class covers the end-to-end supervised learning workflow for text classification: preparing labeled data, splitting into train/validation/test sets, choosing and training classifiers, evaluating performance, and improving models via hyperparameter tuning. Class emphasizes practical model choices (logistic regression, naive Bayes, SVM, kNN, decision trees, ensembles) and evaluation (confusion matrices, accuracy, F1, ROC).

Modules & Key Concepts

  • Data preparation — splitting datasets, feature extraction, cross-validation strategies, and scikit-learn utilities.
  • Parametric vs Non-parametric models — logistic regression and neural nets (parametric) versus kNN, trees, and SVM (non-parametric), with discussion of model complexity and bias-variance tradeoffs.
  • Logistic regression fundamentals — sigmoid and logit functions, interpreting probabilities, and parameter effects.
  • Model selection & tuning — baseline models, hyperparameter search, and validation to select models that outperform baselines.
