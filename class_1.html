Class 1 — Natural Language Processing Fundamentals

This class introduces natural language processing fundamentals through practical text cleaning, tokenization, and preprocessing workflows.

Class 1 is focused on turning raw text into useful tokens and reducing vocabulary size while preserving meaning.

Course Description

This class teaches the fundamentals of NLP preprocessing and early-stage analysis. Topics include basic string manipulation (lower(), split()), regex pattern matching, frequency counting with collections.Counter, tokenization, unicode normalization, contraction handling, stopword removal, spelling correction, stemming, lemmatization, and building reusable preprocessing pipelines.

Modules & Key Concepts

  • Finding simple patterns in text — lowercase, split, regex, Counter(), and most_common() to count tokens and discover frequent words.
  • Preprocessing to reduce vocabulary — parsing raw documents, sentence splitting, normalizing unicode to ASCII, removing punctuation and numbers, and cleaning with NLTK.
  • Pipeline design — a custom Pipe class with chained preprocessing operations exposed as properties like Low, Norm, Exp, Words, Stem, Stop, and NoNum.
  • Stemming and lemmatization — nltk.stem.PorterStemmer, WordNetLemmatizer, and POS-aware lemma conversion to reduce vocabulary variance.
  • Parsing and tagging — nltk.sent_tokenize(), nltk.word_tokenize(), nltk.pos_tag(), Penn Treebank to WordNet POS conversion, and nltk.RegexpParser chunking for phrase extraction.

Course Project / Tasks

Hands-on tasks include initializing pipeline attributes in __init__(), formatting output with Out(), implementing preprocessing steps as @property methods, and validating inputs with assertions such as assert isinstance(LsWords, list).

Practical examples cover NLTK downloads, Brown corpus processing, stopword removal, contraction expansion, HTML tag removal, and spell correction with textblob or custom regex-based fixes.
