Class 1 — Natural Language Processing Fundamentals

This class introduces core natural language processing ideas: keyword extraction, similarity, topic awareness, and extraction of summary text.

Use these notebooks to explore NLP fundamentals before moving into numeric vector representations and machine learning.

Course Description

This class introduces core Natural Language Processing (NLP) techniques and practical preprocessing steps used to prepare text for analysis and modeling. Topics include string operations, regular expressions, tokenization, frequency analysis, document cleaning, normalization (unicode/ASCII), spelling correction, stemming and lemmatization, POS tagging, chunking, and building reusable preprocessing pipelines. Tools used: Python standard library, nltk, textblob, and others.

Modules & Key Concepts

  • Mod 1: Finding Simple Patterns — string methods, regex, counting with collections.Counter, token lists and frequency analysis.
  • Preprocessing to Reduce Vocabulary — tokenization, sentence splitting, unicode normalization, stopword removal, contraction handling, removing HTML, spelling correction, and building a preprocessing Pipe to compose steps.
  • Stemming & Lemmatization — Porter stemmer, WordNet lemmatizer, POS-aware lemmatization to reduce vocabulary size.
  • Tagging & Parsing — sentence/word tokenizers, nltk.pos_tag(), POS-to-WordNet tag conversion, nltk.RegexpParser chunking, building chunk trees and shallow parsing.

Course Project / Tasks

Hands-on project tasks include implementing a preprocessing pipeline class with methods/properties like Low(), NoNum(), Words(), Stop(), Norm(), Exp(), Stem(), Lem(), writing assertion checks, and timing pipeline steps with IPython magics (e.g., %time).
