Class 4 — Topic Modeling With Unsupervised Machine Learning

This class introduces unsupervised topic and summary modeling techniques that help identify latent structure in text.

Explore topic extraction, matrix decomposition, and summary extraction with these notebooks.

Course Description

This class focuses on unsupervised methods to discover latent structure in text: identifying keywords and collocations, extracting keyphrases, dimensionality reduction (SVD/TruncatedSVD), and topic modeling (LSA and LDA). It also covers extractive summarization techniques using LSA and PageRank-style algorithms (TextRank) and practical keyword extraction methods (RAKE, PKE/TextRank).

Modules & Key Concepts

  • Identify Keywords & Keyphrases — collocations, pointwise mutual information (PMI), RAKE, TextRank, and keyword quality evaluation using Jaccard similarity.
  • Matrix decomposition & LSA — SVD, truncated SVD, and approximating matrices for topic discovery and dimensionality reduction.
  • Topic modeling — Latent Semantic Analysis (LSA), Latent Dirichlet Allocation (LDA), and interpreting topic-word distributions, with optional visualization through pyLDAVis.
  • Summary extraction — extractive summarization using sentence scoring, Gramian similarity matrices, PageRank-style ranking, and graph-based sentence selection.
  • Modeling vocabulary — n-gram/phrase extraction, keyword scoring, and comparing RAKE vs TextRank keyword lists.
