Class 4 — Topic Modeling With Unsupervised Machine Learning

This class introduces unsupervised topic and summary modeling techniques that help identify latent structure in text.

Explore topic extraction, matrix decomposition, and summary extraction with these notebooks.

Course Description

This class focuses on unsupervised methods to discover latent structure in text: identifying keywords and collocations, extracting keyphrases, dimensionality reduction (SVD/TruncatedSVD), and topic modeling (LSA and LDA). It also covers extractive summarization techniques using LSA and PageRank-style algorithms (TextRank) and practical keyword extraction methods (RAKE, PKE/TextRank).

Modules & Key Concepts

  • Identify Keywords & Keyphrases — collocations, PMI scoring, RAKE, TextRank, and keyword quality evaluation (Jaccard comparisons).
  • Matrix decomposition & LSA — SVD decomposition, truncated SVD, and approximating matrices for topic extraction and dimensionality reduction.
  • Topic modeling — Latent Semantic Analysis (LSA) and Latent Dirichlet Allocation (LDA), interpretation challenges, and visualization with pyLDAVis.
  • Summary extraction — extractive summarization using frequency-based scoring, LSA, and PageRank-based sentence ranking.
