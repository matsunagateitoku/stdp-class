Lab 1.01 Python Fundamentals

Core Data Structures

Python has five core built-in container types. Understanding which to use matters because they have different performance characteristics and rules about mutability (whether contents can change after creation).

List

Ordered, mutable, can hold mixed types. The most flexible container. Use when you need to add, remove, or reorder items.

a = [1, "hello", 3.14]

Access by index: a[0] → 1. Append: a.append(x). Remove: a.pop().

Tuple

Ordered, immutable — cannot be changed after creation. Faster than lists. Used for fixed collections like coordinates or database rows returned by .items().

t = (1, 2, 3)

Unpacking: x, y, z = t assigns each element to a variable.

Set

Unordered collection of unique elements. Automatically removes duplicates. Useful for membership testing and deduplication.

s = {1, 2, 3, 2} → {1, 2, 3}

Fast in lookups: 2 in s → True.

Dictionary

Unordered collection of key-value pairs. Each key must be unique. This is the go-to structure for structured/labeled data.

d = {"name": "Alice", "age": 30}

Access: d["name"] → "Alice". Update: d["age"] = 31.

Array (NumPy)

Fixed-size sequence of same-type elements. Much faster than Python lists for math. The foundation of all ML work in this course.

import numpy as np
a = np.array([1, 2, 3])

Dictionary Methods — Important for Exam

These three methods are the main ways to iterate over a dictionary. The .items() method is especially important — it returns tuples of (key, value) pairs, making it easy to loop over both at once. This pattern appears throughout the course labs and practice tests.

d = {"name": "Alice", "age": 30, "city": "NY"} d.keys() # dict_keys(['name', 'age', 'city']) d.values() # dict_values(['Alice', 30, 'NY']) d.items() # dict_items([('name','Alice'), ('age',30), ('city','NY')]) # The classic iteration pattern: for key, value in d.items(): print(f"{key}: {value}")

List Comprehensions

A list comprehension is a compact way to build a new list by transforming or filtering an existing one. It is faster than a traditional for loop for the same task and is considered idiomatic Python. The general form is: [expression for item in iterable if condition].

# Basic: square each number squares = [x**2 for x in range(10)] # With filter: only even numbers evens = [x for x in range(20) if x % 2 == 0] # Flatten a nested list (appears in exam quiz-average problem) nested = [[1,2], [3,4], [5,6]] flat = [item for sublist in nested for item in sublist] # Result: [1, 2, 3, 4, 5, 6]

Enumerate — Iterating with an Index

enumerate() wraps any iterable and yields (index, value) tuples. This is the correct way to loop when you need both the position and the value — avoids the clunky range(len(...)) pattern.

colors = ["red", "green", "blue"] for i, color in enumerate(colors): print(f"{i}: {color}") # 0: red # 1: green # 2: blue

Exception Handling (try / except)

When code might fail — file not found, bad type conversion, network error — wrap it in a try/except block. Without this, a single error crashes the whole program. In the course labs, this pattern appears in the MongoDB exam question where the loop iterates over objects and gracefully handles index-out-of-range errors.

try: result = int("not_a_number") # This will raise ValueError except ValueError as e: print(f"Conversion failed: {e}") except Exception as e: print(f"Unexpected error: {e}") # Catches anything else finally: print("This always runs") # Cleanup goes here

NumPy Core Operations

NumPy is the numerical computing backbone of all ML in Python. It stores data in C-optimized arrays and performs operations orders of magnitude faster than Python lists. Every sklearn and TensorFlow function ultimately works with NumPy arrays.

import numpy as np a = np.array([1, 2, 3, 5, 7, 11, 13, 17]) a.shape # (8,) — tuple of dimension sizes a.ndim # 1 — number of dimensions a.reshape(2, 4) # reshape into 2 rows, 4 cols # 2D array slicing — critical for data work data = np.genfromtxt("data/counts.tsv") data[:, 1] # all rows, column index 1 (second column) data[:-12, 1] # all rows except last 12, column 1 np.nan_to_num(data) # replace NaN with 0 np.median(data[:, 1]) # median of a column np.mean(data[:, 1]) # mean np.std(data[:, 1], ddof=1) # sample standard deviation
ddof=1 explained: When calculating standard deviation from a sample (not the whole population), use ddof=1. This applies Bessel's correction — dividing by n–1 instead of n — which gives a less biased estimate. In almost all real-world ML work, you have a sample, so ddof=1 is the right choice.

Labs 1.03 – 1.04 Data Access: SQL, MongoDB & SSH

Why Databases Matter for Cybersecurity ML

Before you can build any ML model, you need data. In security contexts, that data often lives in relational databases (logs, events, alert records) or document stores (unstructured threat intelligence, scraped data). This section covers the mechanics of pulling that data into Python so you can feed it into your models.

PostgreSQL with psycopg2

psycopg2 is the standard Python adapter for PostgreSQL. The workflow always follows the same three steps: (1) create a connection, (2) create a cursor from that connection, (3) execute SQL and fetch results. The cursor is the object that actually executes queries — you never query directly on the connection object.

Connect and query
import psycopg2 db = psycopg2.connect( host="595data.enclaveforensics.com", database="news", user="sans", password="training" ) # Step 1: create cursor cursor = db.cursor() # Step 2: execute query cursor.execute(""" SELECT * FROM headlines LIMIT 10 """) # Step 3: fetch results results = cursor.fetchall() # returns list of tuples _ = [print(i) for i in results]
Inspect database metadata (exam pattern)
# What columns exist in a table? cursor.execute(""" SELECT column_name, data_type FROM information_schema.columns WHERE table_name = 'pg_database' """) result2 = cursor.fetchall() _ = [print(i) for i in result2] # Query specific fields cursor.execute(""" SELECT datacl, datname FROM pg_database """) result3 = cursor.fetchall() # datacl for 'news' row = None (exam answer)
Exam note: An SQL inner join returns rows where data matches in BOTH tables, and includes columns from both. A database is defined as "a collection of tables" — not a file, not an API, not a single table. Think of it like an Excel workbook: each sheet is a table, and the workbook is the database.

MongoDB with pymongo and mongoengine

MongoDB is a document store — instead of rows in tables, it stores JSON-like documents in collections. This is useful for unstructured data like scraped web content or threat intelligence feeds where the schema isn't fixed. pymongo is the low-level driver; mongoengine adds an object-document mapper (ODM) layer so you can define Python classes that map to MongoDB documents.

The key difference from SQL: MongoDB has no strict schema by default. Documents in the same collection can have different fields. This is why the exam emphasized using find_one() to inspect the structure before writing your class definition.

Connect and explore

IntField() and LongField() store specific integer types and will reject non-integer data. MultiLineStringField is a GeoJSON type for storing geographic coordinate lists — not for general text. ID fields are a standard NoSQL feature. MongoDB console command to list databases: show dbs.

SSH with Paramiko

The paramiko library lets you execute shell commands on remote machines from Python. This is used in the course for pulling data from remote servers to analyze. The workflow: create an SSH client, set a policy for unknown hosts, connect, execute a command, read the output.

import paramiko ssh = paramiko.SSHClient() # AutoAddPolicy automatically accepts new host keys (use carefully in prod) ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy()) ssh.connect("hostname", username="user", password="pass") stdin, stdout, stderr = ssh.exec_command("ls -la /var/log") output = stdout.read().decode() print(output) ssh.close()
Labs 2.01 – 2.03 Descriptive Statistics & Data Scaling

Why Statistics for Cybersecurity?

Descriptive statistics let you characterize data without having to look at every individual point. In security contexts, this is powerful: you can detect anomalies (a host sending unusual amounts of data), identify encrypted files (by their statistical uniformity), and determine which features are most useful for classification models. These techniques work on any numerical data — network flows, file sizes, request rates, byte values.

Measures of Central Tendency

Mean (Average)

Sum of all values divided by count. Sensitive to outliers — a single extremely large value pulls the mean upward significantly. Good for symmetric, well-behaved distributions.

np.mean(data)

Example: [1, 2, 3, 4, 100] → mean = 22. The 100 drags it up even though most values are near 2–3.

Median

The middle value when sorted. Not affected by outliers. Better than mean for skewed data like network packet sizes or financial data.

np.median(data)

Example: [1, 2, 3, 4, 100] → median = 3. The 100 has no effect. Exam answer: 24543.5

Measures of Spread / Deviation

Knowing the center of your data isn't enough — you also need to know how spread out it is. Three measures of spread, each with different properties:

Variance

The average of the squared differences from the mean. Squaring ensures that negative and positive deviations don't cancel out, and gives extra weight to large deviations.

Formula: Σ(xi − mean)² / (n−1)

Problem: the result is in squared units (e.g., "square meters" if measuring meters), which is hard to interpret intuitively. That's why we take the square root → standard deviation.

Standard Deviation

The square root of variance. This puts the spread measure back in the same units as the original data, making it interpretable. If your data is in bytes, std dev is also in bytes.

np.std(data, ddof=1) — ddof=1 for sample data

High std dev = data is widely spread. Low std dev = data is clustered tightly around the mean. Encrypted data has very high, consistent std dev because all byte values are equally likely.

Median Absolute Deviation (MAD)

The most robust measure of spread — not influenced by outliers at all. The calculation:

  • Find the median of the dataset
  • Subtract the median from each value and take the absolute value
  • Find the median of those absolute differences

Because it uses medians throughout (not means), a single extreme value cannot distort the result. Preferred for heavy-tailed distributions.

Computing all three deviation measures
import numpy as np data = np.array([10, 20, 30, 40, 50, 1000]) # note the outlier # Variance variance = np.var(data, ddof=1) print(f"Variance: {variance:.2f}") # heavily inflated by 1000 # Standard deviation std_dev = np.std(data, ddof=1) print(f"Std Dev: {std_dev:.2f}") # square root of variance, same scale as data # Median Absolute Deviation (manual — scipy also has it) median = np.median(data) abs_deviations = np.abs(data - median) mad = np.median(abs_deviations) print(f"MAD: {mad:.2f}") # unaffected by the 1000
Exam: which measure is most robust to outliers? Always MAD (Median Absolute Deviation). Standard deviation translates variance to the same scale as the data — this is its key advantage over raw variance. Robust Scaling uses median + IQR for the same robustness reason.

Data Scaling — Why It Matters

Many ML algorithms measure distance between data points (K-Means uses Euclidean distance; SVM uses dot products). If one feature ranges from 0–1 and another from 0–1,000,000, the large-scale feature will dominate all distance calculations and the small-scale feature will have essentially zero influence. Scaling normalizes all features to a comparable range so every feature contributes fairly.

MinMax Scaler

Scales every feature to exactly the [0, 1] range. Formula: (x − min) / (max − min). Simple and intuitive, but sensitive to outliers — one extreme value will compress all other values into a tiny range.

Use when you know your data has no extreme outliers and you need values in a specific bounded range.

StandardScaler

Transforms data to have zero mean and unit variance. Each feature: subtract the mean, divide by std dev. Result: values are centered at 0, most fall between -3 and +3.

The go-to scaler before PCA, KMeans, DBSCAN, and SVM. Works well when data is approximately normally distributed.

from sklearn.preprocessing import StandardScaler

Robust Scaler

Uses the median and interquartile range (IQR) instead of mean and std dev. Because these statistics ignore the extremes, outliers have no effect on the scaling. Best choice for data with significant outliers or heavy-tailed distributions.

from sklearn.preprocessing import RobustScaler

StandardScaler in practice
from sklearn.preprocessing import StandardScaler scaler = StandardScaler() scaler.fit(X_train) # compute mean and std from training data only X_train_scaled = scaler.transform(X_train) X_test_scaled = scaler.transform(X_test) # use SAME scaler on test data! # Never fit on test data — that would leak information

Detecting Encrypted Data with Statistics

This lab showed a practical security application of descriptive statistics. Normal files (text, images, executables) have non-uniform byte distributions — certain byte values appear much more frequently than others. Encrypted data, by design, looks like random noise — all 256 byte values appear with roughly equal frequency. You can detect this by looking at the histogram (should be flat for encrypted data) or the standard deviation of byte-value counts (should be very low — no byte value stands out).

Lab 2.04 Probability & Bayes' Theorem

The Core Problem: Classification Under Uncertainty

We rarely know for certain whether an event is malicious or benign. We have evidence (features of a network packet, words in an email, process behavior) and we want to compute the probability of a given outcome. Bayes' Theorem gives us a principled mathematical way to do this by combining prior knowledge (how common is malware in general?) with the likelihood of observed evidence.

Bayes' Theorem

The formula: P(Y|X) = P(X|Y) × P(Y) / P(X)

Reading it in plain English: "The probability of Y being true given that we observed X, equals: the probability of observing X if Y were true, times the base rate of Y, divided by the overall probability of observing X."

P(Y|X) = P(X|Y) × P(Y) / P(X) "probability of Y given X = likelihood × prior / evidence"
P(Y|X)Posterior — what we want to know. "What is the probability of Y being true now that I've seen X?" This is the updated belief after observing evidence.
P(X|Y)Likelihood — "How likely is it to observe this evidence X, if Y is actually true?" E.g., "How likely is this email to contain these words, if it actually is spam?"
P(Y)Prior — the base rate. "How common is Y in general, before I've seen any evidence?" E.g., "What fraction of all emails are spam?"
P(X)Evidence — "How common is this evidence overall, regardless of Y?" Often used as a normalizing constant.
Exam calculation: P(X|Y)=0.08, P(Y)=0.15, P(X)=0.06
P(Y|X) = 0.08 × 0.15 / 0.06 = 0.012 / 0.06 = 0.20 (20%)

Naive Bayes Classifier

The Naive Bayes classifier applies Bayes' Theorem to classification problems like spam detection. It is "naive" because it makes the simplifying assumption that all features (e.g., all words in an email) are probabilistically independent of each other — seeing the word "free" doesn't change the probability of seeing "money" in the same email. This assumption is almost never literally true, but in practice the classifier still works remarkably well.

The algorithm works by computing, for each class (spam/not-spam), the probability that a document with these features belongs to that class. It picks the class with the highest probability.

Frequentist Approach

Counts raw occurrences of events. "Out of 1000 emails, 150 were spam. Therefore spam probability = 15%." No prior probability is used. Results depend entirely on what was observed in the training data.

Bayesian Approach

Starts with a prior belief and updates it as new evidence arrives. This is more principled when you have prior knowledge and allows the model to handle new data gracefully. Email spam filters are the canonical real-world example.

Lab 2.05 Signals & the Fourier Transform

Why Signal Analysis in Cybersecurity?

Network traffic, system call counts, log event rates — these are all time series: sequences of values measured at regular intervals. Hidden within these sequences can be periodic patterns (a process phoning home every 60 seconds, a clock signal in firmware, a periodic scan) that are invisible when you look at raw values but become obvious when you decompose the signal into its frequency components. That's what the Fourier Transform does.

Fourier's Core Insight

Jean-Baptiste Joseph Fourier showed that any periodic function can be represented as a sum of sine waves of different frequencies and amplitudes. This is profound: no matter how complex or irregular a repeating signal looks, it can be expressed as a combination of simple, pure sine waves.

The practical implication: take any time series (network packet counts per second, CPU usage over time), apply the Fourier Transform, and you get a list of frequencies and their strengths. Prominent frequencies correspond to repeating patterns in your data. A spike at frequency F means something repeating with period 1/F seconds.

Example: a square wave (like a digital clock signal, or binary network traffic) looks very different from a sine wave, but it can be built up from a sine wave plus harmonics with two, three, and four terms — each term making the waveform more "square-like."

The Nyquist Frequency (Shannon Limit)

There is a fundamental limit to what frequencies you can detect given your sampling rate. The Nyquist-Shannon sampling theorem states that to accurately detect a frequency F, you must sample at least 2F times per second. Equivalently, the highest frequency you can detect is exactly half your sampling rate.

Nyquist Frequency = Sampling Rate / 2 Detectable range: 0 Hz to Sf / 2
Sampling rate 300 kHzNyquist = 150 kHz — you can detect frequencies from 0 to 150,000 Hz
Sampling rate 86,400/dayNyquist = 43,200 — you can detect cycles as fast as 2 per day
Sampling rate 600 kHzNyquist = 300 kHz
Exam: sampling rate 300 kHz → Nyquist = 150 kHz. If you sample too slowly (below twice the signal frequency), you get aliasing — the signal appears at a false, lower frequency. The Shannon Limit is a hard physical/mathematical constraint.

Sine Wave Properties

Important for the exam — know these four attributes of sine functions:

  • Periodic: the pattern repeats at regular intervals (the "period")
  • Continuous: no jumps or breaks in the function
  • Trigonometric: defined by a ratio in a right triangle — NOT a polynomial function
  • Cycles infinitely: the oscillation between +1 and −1 never stops
Using NumPy's rfft for real-valued signals
from numpy.fft import rfft import numpy as np # rfft = "real Fast Fourier Transform" # Use for real-valued signals (not complex) # Returns only the positive frequency components (half the spectrum) signal = np.array([...]) # your time-series data frequencies = rfft(signal) # The magnitude tells you how strong each frequency component is magnitudes = np.abs(frequencies) # Nyquist: valid frequencies are 0 to sampling_rate/2 # Any component beyond Nyquist is aliasing, not real signal
Labs 3.01 – 3.03 Clustering: K-Means, Elbow Method, DBSCAN & PCA

What is Clustering?

Clustering is unsupervised learning — you don't have labels telling you which class each data point belongs to. Instead, the algorithm discovers natural groupings in the data on its own. In cybersecurity, clustering is useful for: grouping similar network connections, identifying families of malware, finding unusual clusters of user behavior (anomalies), and exploring large unlabeled datasets.

K-Means Clustering

K-Means divides data into exactly k clusters. The algorithm:

  • Randomly initializes k centroids (one per cluster)
  • Assigns each data point to its nearest centroid (measured by Euclidean distance)
  • Recomputes each centroid as the mean of all points assigned to it
  • Repeats until centroids stop moving (convergence)

A centroid is the geometric center of a cluster — the mean (average) position of all points in that cluster. K-Means uses Euclidean distance, which means all features must be on comparable scales — always scale your data before K-Means.

Critical: K-Means assumes clusters are roughly spherical and equally sized. It performs poorly on irregular shapes. For arbitrary-shape clusters, use DBSCAN instead.
K-Means full workflow
from sklearn.cluster import KMeans from sklearn.preprocessing import StandardScaler import pandas as pd # 1. Prepare data — K-Means needs all-numeric input df = pd.get_dummies(df, columns=['protocol']) # one-hot encode text fields df['port'] = pd.to_numeric(df['port'], errors='coerce') df.drop('timestamp', axis=1, inplace=True) # drop irrelevant columns df = df.dropna() # drop rows with NaN # 2. Scale — required before K-Means scaler = StandardScaler() X_scaled = scaler.fit_transform(df.to_numpy()) # 3. Cluster km = KMeans(n_clusters=4, random_state=42) km.fit(X_scaled) labels = km.labels_ # cluster assignment for each row (0, 1, 2, 3) # 4. Examine results df['cluster'] = labels print(df.groupby('cluster').mean()) # profile each cluster

The Elbow Method — Choosing k

K-Means requires you to specify k (number of clusters) in advance, but you often don't know the right k. The elbow method helps you find it algorithmically.

The metric used is WCSS (Within-Cluster Sum of Squares) — the total squared distance from each point to its assigned centroid. When k is too small, clusters contain dissimilar points, so WCSS is large. As k increases, clusters get tighter and WCSS decreases. At some point, adding more clusters gives diminishing returns — the improvement in WCSS per additional cluster drops sharply. This inflection point (the "elbow") is the optimal k.

wcss = [] k_range = range(1, 11) for k in k_range: km = KMeans(n_clusters=k, random_state=42) km.fit(X_scaled) wcss.append(km.inertia_) # inertia_ = WCSS import matplotlib.pyplot as plt plt.plot(k_range, wcss, 'bo-') plt.xlabel('Number of clusters (k)') plt.ylabel('WCSS') plt.title('Elbow Method — find the bend') # Look for where the slope flattens — that k is your answer

DBSCAN — Density-Based Clustering

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) takes a completely different approach from K-Means. Instead of assigning every point to a cluster, it identifies regions of high density and calls everything else noise. This makes it especially good for anomaly detection.

DBSCAN defines clusters based on two parameters: eps (the maximum distance between two points to be considered neighbors) and min_samples (minimum number of neighbors required to form a dense region). Points with enough neighbors form clusters; isolated points get label -1 (noise/anomaly).

Key advantages over K-Means: doesn't require specifying k, handles arbitrarily shaped clusters, and naturally identifies outliers as noise. In security work, those noise points (label = -1) are your anomalies.

from sklearn.cluster import DBSCAN from sklearn.preprocessing import StandardScaler # Scale first (DBSCAN is distance-based) scaler = StandardScaler() scaled = scaler.fit_transform(data) db = DBSCAN(eps=0.5, min_samples=5) labels = db.fit_predict(scaled) # Anomalies = points with label -1 anomalies = data[labels == -1] print(f"Found {len(anomalies)} anomalous records")

PCA — Principal Component Analysis

PCA is a dimensionality reduction technique. When you have many features (say, 50 columns in your dataframe), it's hard to visualize the data or understand its structure. PCA finds new axes — called principal components — that capture the most variance in the data, and projects your data onto those axes. You can then keep just 2 or 3 components for visualization while retaining most of the information.

Eigenvectors and eigenvalues are the mathematical backbone of PCA. An eigenvector of a matrix is a special vector that, when multiplied by the matrix, only scales (doesn't rotate). The scaling factor is the eigenvalue. In PCA, eigenvectors are the principal component directions, and eigenvalues tell you how much variance each component captures. The eigenvector with the largest eigenvalue is the first (most important) principal component.

Exam: eigenvectors = principal components. The largest eigenvalue corresponds to the component that explains the most variance. Exam answer: 4.50000000 (largest eigenvalue). Eigenvectors can act as "axes within a data sample" to measure loss/variance.
from sklearn.decomposition import PCA from sklearn.preprocessing import StandardScaler # Always scale before PCA scaler = StandardScaler() scaled = scaler.fit_transform(data) # Reduce to 3 dimensions for visualization pca = PCA(n_components=3) reduced = pca.fit_transform(scaled) # How much variance does each component explain? print(pca.explained_variance_ratio_) # e.g., [0.42, 0.28, 0.15] means first 3 components explain 85% of variance # 3D scatter plot (Matplotlib) from mpl_toolkits.mplot3d import Axes3D import matplotlib.pyplot as plt fig = plt.figure() ax = fig.add_subplot(111, projection='3d') ax.scatter(reduced[:,0], reduced[:,1], reduced[:,2])

Labs 3.04 – 3.05 Support Vector Machines & Kernel Functions

What is a Support Vector Machine?

An SVM is a supervised classification algorithm. Given labeled training data (examples tagged as "malicious" or "benign"), it learns a decision boundary that separates the two classes. What makes SVMs special is how they choose that boundary: they maximize the margin — the gap between the boundary and the nearest training examples from each class. A wider margin generally means better generalization to new data.

By convention: X = training data (features), Y = training labels (expected outputs). This notation is universal across sklearn and TensorFlow.

Key Concepts

Hyperplane

The decision boundary. In 2D data, it's a line. In 3D, it's a plane. In higher dimensions, it's a hyperplane — a flat subspace one dimension lower than the data space. The SVM finds the hyperplane that best separates the classes.

Margin

The distance between the hyperplane and the closest data points from each class. The SVM's goal is to maximize this margin. A larger margin means more breathing room — the classifier is less likely to misclassify new points that are slightly different from training data.

Support Vectors

The data points from each class that lie closest to the hyperplane. These are the only points that matter for defining the boundary — moving any other point wouldn't change the result. The "support" in the name refers to how these points literally support (define) the hyperplane.

Soft Boundary (Soft Margin)

A hard boundary requires perfect separation — every training point must be on the correct side. A soft boundary allows some points to be on the wrong side of the margin, trading perfect training accuracy for better generalization. In security: not every repeat failed login is malicious — soft boundaries accommodate these edge cases instead of forcing a hard threshold.

The Kernel Trick

Many real-world datasets are not linearly separable — you can't draw a straight line (or flat hyperplane) to separate the classes. One solution: project the data into a higher-dimensional space where it becomes linearly separable, then find the hyperplane there.

The kernel trick makes this computationally feasible. Instead of actually computing the high-dimensional coordinates (which would be expensive), a kernel function computes the dot product of two points in that high-dimensional space directly from the original coordinates. This gives us the power of high-dimensional separation without the cost. Think of it as "adding dimensions" to the problem so the boundary can flex and curve.

Linear ('linear')

No transformation — uses the original feature space. The boundary is a flat hyperplane. Fast and interpretable. Use when your data is already linearly separable (or close to it).

Polynomial ('poly')

Maps data into a polynomial feature space. Can capture interactions between features (e.g., x₁ × x₂). degree controls the polynomial degree (default 3); higher degree = more complex boundary. coef0 is the constant term.

RBF / Gaussian ('rbf')

The Radial Basis Function kernel. Measures similarity between points using Gaussian (bell-curve) distance. The most commonly used kernel — works well in practice for most problems. gamma controls how far influence of each training point reaches.

Sigmoid ('sigmoid')

Based on the hyperbolic tangent function — similar to the activation function in neural networks. Less commonly used. Parameters: gamma and coef0.

RBF kernel: k(xi, xj) = e^(−γ ‖xi − xj‖²) γ (gamma) controls the "reach" of each training point. High γ: points only influence nearby area → complex, tight boundary. Low γ: influence spreads far → smoother, simpler boundary. The Gaussian kernel is a specific instance of the more general Radial Basis Function. Unlike the Gaussian, γ in the general RBF can be replaced by functions of any order, which is why it is said that RBF can create boundaries in infinite dimensions.

from sklearn.svm import SVC # Train — kernel='linear' is simplest and most interpretable svc = SVC(kernel='linear', verbose=True) svc.fit(X_train, y_train) # Try other kernels: # SVC(kernel='rbf', gamma='scale') — most flexible, often best # SVC(kernel='poly', degree=3) — captures feature interactions # Predict predictions = svc.predict(X_test) # Measure accuracy manually (as done in the lab) accuracy = 0 for i in range(len(y_test)): if y_test[i] == predictions[i]: accuracy += 1 accuracy = accuracy / len(y_test) print(f"Accuracy: {accuracy:.2%}")
AUCROC = Area Under the Receiver Operating Characteristic Curve. It measures classification performance across all possible decision thresholds, not just one threshold. A value of 1.0 = perfect; 0.5 = random guessing. Confusion matrix tells you which categories are being confused for which other categories, and is used to calculate precision (TP / (TP+FP)), recall, and accuracy. Labs 3.06 – 3.07 Decision Trees & Random Forests

Decision Trees

A decision tree is a flowchart-like structure where each internal node tests a feature, each branch represents a test outcome, and each leaf node gives a final prediction. They are among the most interpretable ML models — you can actually trace exactly why a given prediction was made, step by step. This is valuable in security for explainability: "This process was flagged because it had >100 MB network traffic AND it connected to a non-standard port AND it was run by a service account."

Tree Components
  • Root Node: The top — represents the entire dataset. The first split happens here.
  • Internal Nodes: Feature tests ("Is port > 1024?", "Does filename contain .exe?"). Each splits the data further.
  • Branches: The paths connecting nodes — represent the yes/no or range outcome of a test.
  • Leaf Nodes: The bottom — final predictions. In classification: a class label. In regression: a numerical value. Leaf nodes have Gini = 0 (pure — all same class).
How Splitting Works

At each node, the tree tries every possible feature and threshold, and picks the split that best separates the classes. "Best" is measured by the Gini impurity (or entropy): a split is good if the resulting child nodes are more "pure" (dominated by one class) than the parent.

Gini = 0: pure node, one class only. Gini = 0.5: maximum impurity, equal mix of classes. The algorithm greedily minimizes Gini at each step.

Critical Limitations
  • Always classifies: A decision tree cannot say "I don't know." It always produces an output. This is a key weakness for security applications — you can't get a "no match" response.
  • Overfitting: Deep trees memorize training data perfectly but perform poorly on new data. Mitigate with max_depth, min_samples_split, or switch to Random Forest.
  • High variance: Small changes in training data can produce very different trees.
Key exam facts about decision trees: (1) A Decision Tree cannot tell a user if it cannot classify something — it always produces output. (2) Classification always takes a finite number of steps. (3) The bottom (leaf) nodes always have Gini = 0. (4) Gini coefficient of 0.5 = maximum impurity, appears as a threshold on the exam. (5) Decision trees can process large datasets while keeping computation costs low. (6) Many features → risk of overfitting.

Random Forests — Ensembles Fix the Problems

A Random Forest is an ensemble of many decision trees, built using a technique called Bagging (Bootstrap Aggregating). Instead of training one deep tree that overfits, you train many trees on random subsets of the data, and combine their predictions. The intuition: each tree has different errors, but those errors are random and uncorrelated. When you average many imperfect-but-different predictions, the errors cancel out and the signal remains.

The key mechanism: each tree is trained on a bootstrap sample (random sample with replacement — some rows may appear multiple times, others not at all) and considers only a random subset of features at each split. The output of the Bagging process is a set of trees generated from randomly selected features.

For Classification

Each tree votes for a class. The final prediction is the majority vote — the class that most trees voted for.

For Regression

Each tree predicts a number. The final prediction is the average of all trees' predictions.

Gradient Boosting (Different Approach)

Trees built sequentially, each correcting the previous tree's errors. Generally more accurate than Random Forest but slower and more prone to overfitting. Use GradientBoostingClassifier.

Bias vs. Variance: High bias = consistent but wrong (the model is too simple to capture the pattern). High variance = inconsistent — works great on training data but poorly on new data (overfitting). Random Forests reduce variance while keeping bias low. A single deep decision tree has low bias but high variance.

Linear Regression

Linear regression models the relationship between a continuous input variable (x) and a continuous output (y) as a straight line: y = mx + b. The slope m tells you how much y changes for a unit increase in x. The intercept b is the y-value when x = 0. This is used in the course for fitting trend lines to time-series security data (e.g., tracking how byte counts change over time to detect anomalous growth).

y = mx + b m = slope (rate of change) b = y-intercept (value when x = 0) Derivative of y with respect to x = m (constant rate of change)

Bollinger Bands (introduced in Lab 4.01): a financial/signal analysis tool. Three components: (1) a moving average (center line), (2) an upper band at +2 standard deviations, (3) a lower band at −2 standard deviations. Values outside the bands signal unusual activity — applicable to network traffic monitoring just as in financial markets.

What is Machine Learning, Really?

Machine learning is the process where a computer uses an optimization algorithm (like gradient descent) to repeatedly adjust the coefficients in a function, minimizing a loss value, until the function's predictions are as accurate as possible. The model doesn't "understand" — it adjusts numbers until the outputs match the training labels. This is why the course distinguishes between "Machine Learning" and "Understanding."

A derivative is central to this process: it measures how the value of one term in a function changes relative to another. Gradient descent uses the derivative of the loss function with respect to each weight to know which direction to adjust that weight to reduce the loss.

Neural Networks — Architecture

A neural network is a stack of layers, each consisting of neurons. Each neuron takes inputs, multiplies them by weights, sums them, and passes the result through an activation function. The output of one layer becomes the input of the next. By stacking many layers with non-linear activation functions, the network can learn arbitrarily complex patterns.

Hyperparameters

Everything that isn't a learned weight: number of layers, neurons per layer, activation functions, optimizer, learning rate, batch size, epochs, dropout rate. These are chosen by the human, not learned by the model. Tuning them is called hyperparameter optimization.

Bag of Words (BoW)

A text representation method. Build a vocabulary of all unique words in your corpus. Represent each document as a vector: 1 if that word appears, 0 if not (multi-hot encoding). Does not capture word order or meaning — just presence. Despite this limitation, it works well for spam classification because spam emails tend to share distinctive vocabulary.

Autoencoder

A neural network trained to reproduce its own input as output. The network is forced to compress the input through a narrow middle layer (the bottleneck / latent space) and then reconstruct it. What the network learns in the bottleneck is a compact representation of the input's essential structure. When a new input produces high reconstruction error, it's anomalous.

Labs 5.01 – 5.03 Convolutional Neural Networks (CNNs)

What CNNs Do Differently

Standard dense (fully connected) networks treat each input feature independently. CNNs exploit local structure — the idea that nearby values are related. In an image, adjacent pixels form edges and shapes. In a byte sequence (malware binary), adjacent bytes form instructions. In network traffic, adjacent time points form patterns. CNNs use filters (kernels) that slide across the input, detecting local patterns wherever they appear.

The Kernel / Filter in a CNN

A CNN kernel is a small matrix (typically 3×3 or 5×5) of learned weights. The kernel slides across the input (this operation is called convolution), computing a dot product at each position. The result is a feature map — a representation of where and how strongly a particular pattern (edge, motif, byte sequence) appears in the input.

Each layer of a CNN can have many kernels, each learning to detect a different feature. Early layers detect simple features (edges, short byte patterns); deeper layers combine these into complex features (shapes, instruction sequences, protocol structures).

Know BOTH kernel definitions for the exam:
• CNN kernel = a filter (3×3 or 5×5 matrix) applied to input data via convolution. Detects features.
• SVM kernel = a mathematical function that adds dimensions to enable non-linear decision boundaries.
These are completely different concepts that share the same word. The exam tests this distinction directly.

Convolution Padding

When a kernel slides over the input, what happens at the edges? Two common strategies:

  • Valid convolution (no padding): The kernel never goes outside the input. Output is smaller than the input — specifically, it shrinks by (kernel_size − 1) in each dimension. A 3×3 kernel on a 10×10 input gives an 8×8 output. This is the exam-relevant case: valid convolution results in a reduction in the overall size of the matrix.
  • Same convolution (zero-padding): The input is padded with zeros around the border so the kernel can cover the edges. Output size matches input size. Used when you want to preserve spatial dimensions.

Autoencoders in CNNs

A convolutional autoencoder uses CNN layers for both compression and reconstruction. The encoder path uses convolutions to progressively compress the input. The bottleneck (latent space) is the most compressed representation — it has learned to encode the essential structure of the input. The decoder path uses deconvolutions (transposed convolutions) to reconstruct the original. High reconstruction error = anomaly.

Exam definition: An autoencoder is "a network trained to match its output to the input data." The intent is to learn the essence of the input. The bottleneck layer = latent space. A kernel in CNNs is a filter applied to input data. A confusion matrix tells which categories are confused for which other categories. A logistic regression performs categorization problems.

Security Applications of CNNs

  • Malware detection: Treat a binary file's bytes as a 1D or 2D sequence; a CNN learns byte patterns that distinguish malware families from benign files.
  • Ham vs. Spam (CNN style): Treat text as sequences of character or word embeddings; CNN kernels detect n-gram patterns that signal spam.
  • Protocol anomaly detection: Model network packets as byte sequences; the CNN learns what valid protocol structure looks like and flags deviations.
  • Log anomaly detection: Encode log entries as sequences; train an autoencoder on normal logs, then flag high-reconstruction-error entries as anomalies.
  • CAPTCHA solving: Classic image recognition task — CNNs learn visual character patterns to identify characters in CAPTCHAs.
All Labs Loss Functions & Activation Functions

What is a Loss Function?

A loss function quantifies how wrong the model's predictions are. It produces a single number — the loss — that summarizes the discrepancy between predicted and actual values across the training set. During training, the optimizer (typically gradient descent) adjusts the model's weights to minimize this loss. Choosing the right loss function for your task matters enormously: the wrong choice can cause the model to fail to converge or optimize for the wrong objective.

Loss Functions

Mean Squared Error (MSE)

Average of squared differences between predicted and actual values. Because errors are squared, large errors are penalized much more than small ones — the slope of the loss increases as error grows. This can be a problem: a single large outlier can dominate the loss and cause the optimizer to chase it at the expense of everything else.

Problem: vanishing loss — if your predictions are very close to the targets, MSE can become so small that gradient descent can no longer make meaningful updates.

Root Mean Squared Error (RMSE)

Square root of MSE. This returns the error to the same units as the original data (interpretable). More importantly, it is the fix when the loss vanishes — RMSE keeps gradients meaningful even when errors are small. If your model stops improving because MSE is near zero but accuracy is still poor, switch to RMSE.

Mean Absolute Error (MAE)

Average of absolute (not squared) differences. Treats all error magnitudes equally — a large error is not penalized disproportionately. More robust to outliers than MSE, but its gradient is constant (doesn't change near zero), which can slow convergence.

Huber Loss

Combines the best of MSE and MAE. For small errors (below a threshold δ), it behaves like MSE (smooth gradients). For large errors (above δ), it behaves like MAE (doesn't explode). Use when a network fails to converge because the difference between output and input becomes very large — it prevents the loss from growing out of control.

Binary Cross-Entropy

The standard loss for binary classification (spam/not-spam, malware/benign). Works with a sigmoid activation on the output layer. Penalizes confident wrong predictions very heavily — if you say "99% probability of spam" but it's not spam, the loss is very large. This is the loss function for ham vs. spam classifiers.

Categorical Cross-Entropy

For multi-class classification. Calculated as the sum of logarithms of all softmax activations for the correct class predictions. Works with a softmax output layer that produces a probability distribution across all classes. Use when you have more than two possible output classes.

Gradient Descent — The Optimizer

Gradient descent is the algorithm that actually trains the network. After each batch of training examples, it computes the gradient of the loss function with respect to every weight — this is the direction in weight-space that would increase the loss the most. Gradient descent then moves the weights in the opposite direction (downhill), reducing the loss. The step size is the learning rate.

Most named optimizers (Adam, RMSProp, Adagrad, SGD with momentum) are all variations of gradient descent that add techniques like adaptive learning rates or momentum to converge faster and more reliably. If asked what approach minimizes the loss function in deep learning: gradient descent.

Activation Functions

An activation function determines whether and how strongly a neuron "fires" — it's applied to the weighted sum of inputs before passing the result to the next layer. Without non-linear activation functions, stacking layers would have no benefit (the whole network would collapse to a single linear transformation). Non-linear activations are what give neural networks their expressive power.

ReLU (Rectified Linear Unit)

f(x) = max(0, x). If input is positive, pass it through unchanged. If negative, output zero. Simple, fast, and works well in practice. The most commonly used hidden-layer activation.

Risk: dying ReLU — if a neuron's inputs are always negative, it outputs zero forever and never updates. Leaky ReLU fixes this.

Leaky ReLU

Like ReLU, but for negative inputs, instead of outputting zero, it outputs a small fraction (e.g., 0.01 × input). This prevents neurons from dying. Useful when you have sparse gradients (many zero-gradient situations).

model.add(layers.LeakyReLU(alpha=0.01))

Sigmoid

Squashes input to (0, 1). Used on the output layer for binary classification — the output can be interpreted as a probability. Not good for hidden layers because it saturates (gradients vanish) for very large or very small inputs.

Softmax

Converts a vector of raw scores into a probability distribution that sums to 1. Used on the output layer for multi-class classification. Pairs with categorical cross-entropy loss.

Exam — Dropout: Dropout is a regularization technique, not an activation function. During training, it randomly sets a fraction of neurons' outputs to zero at each step. This forces the network to learn redundant representations and prevents over-reliance on any single neuron. The result: reduced overfitting. model.add(Dropout(0.5)) drops 50% of neurons during training (all neurons active at inference time).
