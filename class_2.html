Class 2 — Transforming Text Into Numeric Vectors

This class focuses on transforming text into numeric vectors and evaluating semantic similarity between words and documents.

Class 2 covers both sparse vector space models and dense pretrained embeddings for text representation.

Course Description

This class teaches how to convert raw text into numeric representations for information retrieval and machine learning. You will build document-term matrices (DTM) and TF–IDF matrices with CountVectorizer and TfidfVectorizer, work with SciPy sparse matrices, and compare dense embeddings from pretrained Gensim models like Word2Vec/GloVe and FastText.

Modules & Key Concepts

  • Sparse vectorization — use CountVectorizer to build DTMs, inspect vocabulary with .get_feature_names(), and convert sparse matrices to dense pandas DataFrames for visualization.
  • TF–IDF — compute term frequency-inverse document frequency matrices, understand fitting vs transforming, and use thresholding to identify important words.
  • Dense word embeddings — load pretrained models with Gensim, inspect KeyedVectors, extract vectors, use .most_similar(), .similarity(), and perform analogy arithmetic.
  • FastText and subwords — generate character n-grams for rare words, build sentence vectors from subword vectors, and handle out-of-vocabulary terms robustly.
  • Similarity measurement — dot product, cosine similarity, Euclidean distance, pairwise cosine similarity matrices, and document similarity using TF–IDF or dense embeddings.
  • Long-tail vocabulary analysis — study word frequency distributions, head/tail thresholds, and how preprocessing and lemmatization improve model quality by collapsing rare forms.

Projects & Practical Notes

Practical tasks include building DTMs, creating TF–IDF matrices, measuring document similarity, exploring pretrained embeddings, and comparing dense vector models with sparse representations. It also covers practical issues such as vocabulary growth, OOV words, and the limits of averaged document vectors.
