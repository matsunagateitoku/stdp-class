Class 2 — Transforming Text Into Numeric Vectors

This class focuses on converting text into numeric form through matrix operations, decomposition, and data preparation for modeling.

These notebooks cover vectorization foundations and the linear algebra needed for text modeling.

Course Description

This class teaches how to convert textual documents into numeric vectors suitable for search, clustering, and classification. You will build sparse representations (document-term matrices and TF–IDF) and work with dense word and sentence embeddings (Word2Vec/GloVe/FastText/SBERT). The class also covers linear algebra operations on vectors and matrices, dimensionality reduction (SVD/PCA), and practical metrics for measuring similarity.

Modules & Key Concepts

  • DTM & TF–IDF — build document-term matrices with CountVectorizer, transform with TfidfVectorizer or TfidfTransformer, and operate on SciPy sparse matrices.
  • Vector/Matrix Operations — dot products, norms, pairwise cosine similarities, dense vs sparse storage, and converting between formats for visualization with pandas and seaborn.
  • Dense Embeddings — loading pretrained Gensim embeddings (GloVe/Word2Vec), extracting vectors, using similarity and most_similar methods, and arithmetic analogies (king - man + woman ≈ queen).
  • FastText & Subwords — subword n-grams to address out-of-vocabulary (OOV) issues and transfer learning for domain-specific post-training.

Projects & Practical Notes

Practical tasks include loading pretrained vectors, computing word and document centroids, comparing documents with cosine similarity, and using embeddings for semantic search. Discusses limitations of averaged document vectors and strategies to weight or improve them (e.g., TF–IDF weighting).
