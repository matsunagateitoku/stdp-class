Class 6 — Conducting Semantic and Sentiment Analysis

This class explores semantic analysis, sentiment detection, and lexical relationships using classic NLP tools and sentiment models.

These notebooks help you connect meaning, emotion, and lexical structure in text.

Course Description

Examine many kinds of semantic relationships that words can have (such as hypernyms, hyponyms, or meronyms), which go a long way toward extracting the meaning of documents at scale. You will also implement named entity recognition to identify proper nouns within a document and use several techniques to determine the sentiment of text: Is the tone positive or negative? These invaluable skills can easily turn the tide in a difficult project for your team at work or on the path toward achieving your personal goals.

Module 1: Conduct Semantic Analysis Using WordNet

Key concepts

  • WordNet — a large lexical database that groups words into synsets and links them via semantic relations: hypernyms, hyponyms, meronyms, holonyms, antonyms, and entailments.
  • Homophones: words that sound the same but have different senses (e.g., buy/by/bye).
  • Homographs: words spelled identically but with different senses (e.g., bat (animal) vs bat (baseball)).
  • Holonym / Meronym relationships: part-whole relations, e.g., lettuce and tomato are meronyms of sandwich (its holonym).

Module 2: Train a Model To Predict Named Entity Tags

Key concepts

  • IOB tagging: inside–outside–beginning tagging scheme for NER annotations.
  • Conditional Random Fields (CRF) for sequence labeling using neighboring-word features and POS tags.

Lessons & Activities

  • Introduction to NER and named entity linking/disambiguation (NEL).
  • IOB tagging examples using the Groningen Meaning Bank (GMB) corpus.
  • Practice building and evaluating a CRF-based NER model with sklearn_crfsuite: NER.ipynb.
  • Course project: train and evaluate a CRF NER model to recognize movie-related entities: Train.ipynb / Train1.ipynb.

Module 3: Conduct Sentiment Analysis

Key concepts

  • Lexicon-based sentiment models (VADER) and simple feature-based models (TextBlob).
  • Sentiment metrics: polarity, valence, objectivity, and discrete polarity labels.

Lessons & Activities

  • VADER: lexicon-based model tuned for short social text, emoticons, and slang. Practice with VADER.ipynb.
  • TextBlob sentiment analyzer and comparisons with VADER: TextBlob.ipynb.
  • Course project: expand VADER's lexicon using TextBlob and compare F1 scores between original and expanded lexicons. Starter and finished notebooks: Conduct2.ipynb / final.ipynb.
